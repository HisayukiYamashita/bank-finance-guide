# 融資の準備室

山下税理士事務所の、銀行融資相談のための質問式資料作成ツールです。静的なHTML・CSS・JavaScriptだけで動作します。

## 機能

- 8ステップの質問から、事業概要・案件経緯・資金使途・返済原資・保全・経営者の意見を整理
- 資金計画の照合と12か月の資金繰り・下振れの簡易計算
- 相談資料のHTMLダウンロード、ブラウザ印刷・PDF保存、資金繰りCSV
- 回答のJSON保存・読み込み。任意で同じ端末への保存
- マニュアルの参照

入力内容の送信、利用者の登録、アクセス解析、外部APIはありません。サイトのURLを共有しても、入力内容は共有されません。保存したファイルには入力情報が含まれます。

## 配置

GitHub Pages: main ブランチのルートを公開元に設定します。
Cloudflare Pages: ビルドコマンドなし、出力ディレクトリはリポジトリのルート。

## 数値の前提

金額は万円。初期生成は同月回収・同月支払い、今回融資は据置なし・元金均等・第1月から返済。利息は月初残高から概算。借入・出資と設備・その他支払いを第1月に配置します。運転資金は一括支出しません。自己資金が期首資金に含まれるかを明示して二重計上を避けます。

月次表は手入力による調整を優先します。上流の基準値を変えただけでは自動更新されないため、必要に応じて作り直すか修正してください。税等の空欄はゼロと見なさず、残高未確定として扱います。下振れは売上回収・変動費のみを一定率で低下させた簡易モデルです。

このツールは融資の可否を判定しません。銀行の実際の返済予定表、月次試算表、中長期損益計画、根拠資料との照合が必要です。
