# 融資の準備室

山下税理士事務所の、銀行融資相談のための質問式資料作成ツールです。静的なHTML・CSS・JavaScriptだけで動作します。

## 機能

- 8ステップの質問から、事業概要・案件経緯・資金使途・返済原資・保全・経営者の意見を整理
- 資金計画の照合と12か月の資金繰り・下振れの簡易計算
- 相談資料のHTMLダウンロード、ブラウザ印刷・PDF保存、資金繰りCSV
- 回答のJSON保存・読み込み。任意で同じ端末への保存
- マニュアルの参照

入力内容の送信、利用者の登録、アクセス解析、外部APIはありません。サイトのURLを共有しても、入力内容は共有されません。保存したファイルには入力情報が含まれます。

## 配置

GitHub Pages: main ブランチのルートを公開元に設定します。
Cloudflare Pages: ビルドコマンドなし、出力ディレクトリはリポジトリのルート。

## 数値の前提

金額は万円。初期生成は同月回収・同月支払い、今回融資は据置なし・元金均等・第1月から返済。利息は月初残高から概算。借入・出資と設備・その他支払いを第1月に配置します。運転資金は一括支出しません。自己資金が期首資金に含まれるかを明示して二重計上を避けます。

月次表は手入力による調整を優先します。上流の基準値を変えただけでは自動更新されないため、必要に応じて作り直すか修正してください。税等の空欄はゼロと見なさず、残高未確定として扱います。下振れは売上回収・変動費のみを一定率で低下させた簡易モデルです。

このツールは融資の可否を判定しません。銀行の実際の返済予定表、月次試算表、中長期損益計画、根拠資料との照合が必要です。

## 更新

`index.html`、`assets/app.js`、`assets/style.css` が入力・出力機能、`manual.html` が参照資料です。`manual.html` に原講義と制度補足の出典を記載しています。講師の公式資料ではありません。

## 書類のインポート

「書類を取り込む」から、文字データを持つPDF、Excel（xlsx/xls）、CSVを端末内で読み取れます。書類の会社名・種類・対象期間・単位・採用列を確認して、年度別の過去実績として保存します。各値にはファイル名とページ／シート・行、採用値・単位を残します。

- 自動候補：BS/PLの主要科目、借入金、減価償却、法人税等の費用、申告所得・確定税額等。
- 複数の数値列は自動確定しません。科目名が一致しない場合は原文行から指定・修正できます。
- 総資産・純資産等を入力欄へ選択反映。月商・減価償却の月平均は、月初〜月末の期間を確認した場合に任意で使用できます。
- 申告税額は納付予定や未納額とは区別し、将来の資金繰り表へ自動投入しません。
- 原本ファイルは回答データに保存しません。確認済み実績・出典はJSONの回答保存と印刷用資料に含まれます。
- 対応上限：1回10ファイル、1ファイル20MB、PDF100ページ、1シート20,000行・80列。スキャン画像・写真・暗号化ファイルは対象外。
- CSVはUTF-8・Shift_JIS・BOM付きUTF-16。数式は保存済み計算結果を読み、再計算しません。
- 各種ソフトのすべての帳票レイアウトへの完全対応を保証するものではありません。原本との照合が必要です。
